# FitMate

Приложение для персонального тренера и клиентов.

- **Telegram-бот** — для клиентов (логирование тренировок, прогресс)
- **Веб-панель** — для тренера (дашборд, карточки клиентов, редактор тренировок)
- **API** — общий бэкенд
- **PostgreSQL** — база данных

## Структура

```
fitmate/
├── apps/
│   ├── api/        # Бэкенд API (Node.js + TypeScript + Fastify)
│   ├── bot/        # Telegram-бот для клиентов (grammY)
│   └── web/        # Веб-панель тренера (React + Vite)
├── packages/
│   └── shared/     # Общие типы и утилиты
└── package.json    # Монорепо (npm workspaces)
```

## Разработка

Требуется Node.js LTS (>= 20) и git.

```bash
npm install        # установка зависимостей во всех пакетах
npm run dev        # запуск всего в режиме разработки
```
